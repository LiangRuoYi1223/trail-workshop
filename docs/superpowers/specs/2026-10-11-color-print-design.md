# 有限颜色地表打印设计

用户于 2026-10-11 明确授权修改代码并按已讨论方案推进。新约束覆盖此前保留全色照片的默认输出：草地一种颜色、山石一种颜色、路线独立颜色，默认最多三种打印颜色；两色模式合并山体颜色。无需重复请求实现许可。

## 结果

Windows v0.4.0 支持 GPX/KML、本地或自动 DEM、本地彩色地表 GeoTIFF。真实影像按地理位置划分植被与非植被，再归并为草地/山石两种代表色；这是 RGB 外观分类，不是精确土地覆盖识别。无影像时统一山体配色并明确提示。地形与路线几何继续使用现有闭合一体模型。底座、外沿及侧墙复用山石色，两色模式复用山体色。路线顶面和可辨识侧面使用路线色。实际打印色数以去重后的调色板计，不将灯光明暗计作新材质。

## 数据与范围

本阶段支持北向 RGB/RGBA GeoTIFF，8 位通道，EPSG:4326 或 EPSG:3857，文件最多 64 MB、像素最多 16,777,216。高程和地表影像拥有独立导入入口，影像需覆盖山体采样位置；缺失覆盖不得伪装成真实地表。用户自行提供具有交付权限的影像。本阶段不连接需账号或付费的卫星服务；自动影像获取属于后续独立数据源扩展。

一体几何与外观分开。外观包含 schemaVersion、固定语义的 faceClasses（grass/rock/route）、去重调色板、faceMaterials、设置、来源元数据和哈希。几何坐标使用同一投影、中心、旋转、mmPerMeter；影像采样依此反算每个面中心的地理坐标。草地判定使用保守绿色优势阈值，非植被归为山石代表色。不能声称从 RGB 精确区分岩石、裸土和建筑。更改颜色仅重建外观与导出，更改影像或取景使几何结果过期。

## 导出

- 标准彩色 3MF：毫米单位、闭合网格、Materials 扩展的三角面颜色属性，最多 3 种唯一 RGB；不伪装成含设备参数的拓竹项目。
- OBJ ZIP：model.obj、model.mtl、限色 palette.png、manifest.json、中文说明，按三角面材质导出，说明毫米尺寸。地表位置和路线颜色与预览一致。
- STL：继续兼容纯几何导出。

3MF 和 OBJ 可交付打印店；标准 3MF 使用目标切片软件的颜色映射。拓竹项目文件由经过验证的 Bambu Studio 导入流程保存，不能直接承诺所有切片软件/版本兼容。交付中保留调色板和来源元数据，方便耗材映射。

## 桌面与保存

新增选择地表影像、清除影像、草地/山石颜色、2/3 色上限和输出格式选择。路线原有色盘保留。恢复旧 GPX/KML 项目兼容；新项目记录影像文件路径、字节数和 SHA，缺失/变化时保留设置并提示重新选择。更改任何外观后清除已保存提示，保存时主进程冻结当前配色；预览与彩色文件引用同一份分类。所有原有保存的覆盖确认、原子发布、取消与任务目录保护继续使用。

## 验证

分类、投影反算、旋转取景、影像范围、色数预算、去重与恶意调色板；GeoTIFF RGB/RGBA、CRS、alpha/nodata、错误输入和像素上限；独立回读 ZIP/3MF/OBJ/PNG，核对面数、坐标、材质、毫米尺寸与最多三色；桌面导入/恢复/缺失/改变、真实 worker 生成和改色后导出；隐藏 Electron 窗口实际导入生成保存；原 GPX/KML、闭合模型和保存检查全部回归。
