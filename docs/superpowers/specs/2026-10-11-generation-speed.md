# 生成提速设计

用户已批准按照讨论顺序实施：合并细碎网络读取，复用下载数据，并行获取影像与高程，分阶段显示进度和设置超时。

保持现有 Sentinel-2 影像细节、草地／山石／路线有限配色、地形及路线几何精度、GPX/KML 和 3MF/OBJ/STL 输出。此次不增加降低影像精度的快速配色模式。

影像读取采用受控的字节块缓存，减少 TIFF 元数据的小范围网络往返；验证过的数据块落盘后，重试和重叠取景可以复用。保留公共来源限制、单请求 4 MB 与每次任务 64 MB 网络预算、取消、完整覆盖和云筛选，最终影像缓存依旧只有完整成功后发布。

影像和高程并行获取。获取完成后进入建模，再进入输出核验。超时按当前阶段报错，网络等待不占用建模的独立时限；仍保留有限的超时和取消能力。

界面分别展示影像与高程状态，并显示下载量、缓存复用、地表覆盖进度及已用时间。总超时不得一律归为影像失败。模型未校验成功时不得允许保存。

验证包含请求数量减少、离线复用、失败重试、重叠取景、损坏缓存、取消清理、预算限制、并行启动、分阶段超时，以及实际联网测量和新版桌面包检查。测速结果注明首次获取或缓存复用，不承诺固定倍率。
