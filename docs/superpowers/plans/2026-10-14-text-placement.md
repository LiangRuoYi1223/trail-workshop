# 文字沿边定位与地图预览 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task.

**Goal:** 圆形凸字可选择周向位置，多边形可选择边并居中，生成前在地图取景显示真实字形。

**Architecture:** 保留现有一行直排凸字，旋转／平移字形到指定边缘。地图由主进程读取本机字体并调用核心同一布局函数，返回毫米字形、外沿和定位报告；地图转换为地理坐标绘制，不重新获取 DEM 或影像。位置属于几何参数，改动后旧模型过期。

**Tech Stack:** TypeScript/Clipper/Leaflet/React/Electron，现有本机字体，增加依赖为零。

**Spec:** 本文件下方设计约定，依据用户 2026-10-14 的实现请求。

## 设计约定

- `baseTextAngleDeg?: number`，默认 180，0–360，360 与 0 同位；0 模型上方、90 右方、180 下方、270 左方，随整个取景的朝向旋转。
- `baseTextEdgeIndex?: number`，默认 0，0–7 的整数；多边形必须小于边数。界面显示第 1–N 边，第 1 边为模型正前方的下边，其后向右沿周边编号。减少边数时界面钳制到最后一条有效边。
- 矩形仍使用原正前方居中位置；圆形位置采用沿圆周的切线，文字整行随位置旋转，非弧形排字。
- 原字号、颜色、0.6 mm 凸起、0.5 mm 安全距离、外沿自动扩展至最多 20 mm、材料闭合与同色计数约束不变。
- `Inspection.baseTextPreview` 返回 `contoursMm`（含孔）、`contoursGeo`（含孔）、`outlineMm`/`outlineGeo`（最终外沿）、`anchorMm`、`anchorGeo`、`rotationDeg`、`effectiveFrameWidthMm`、`edgeCentersMm`/`edgeCentersGeo`；失败时返回 `error`。文字关闭或空白不读取字体、不显示预览。
- 地图保持取景控件；字形按实际尺寸及所选颜色显示，孔洞保留。用户后续明确：圆形需要地图拖拽旋转手柄和绝对角度数字输入；多边形需要地图点击选择边和边序号数字输入。圆形另保留滑块快捷调整。预览错误不使已有路线取景消失，生成仍走原校验。
- 主进程与核心共享布局，预览仅需本机字体与轮廓。拖动取景期间可随轮廓暂时移动，250 ms 检查完成后更新精确字形。关闭文字时移除文字和边缘选择标记。

## Review Focus

1. 圆形 0／360 及四个方向，偏转取景后地图和模型方向一致。
2. 各边数、圆角、减少边数，位置合法且文字严格居中。
3. 字形孔洞与分离笔画、本机缺字、空白与关闭文字，预览失效信息正确。
4. 快速修改，丢弃过期检查结果；改位置／字号需重新生成，改色即时反映。
5. 显示范围纳入外沿文字；选择边标记不遮挡中心、顶点／旋转交互，960×720 可操作。
