# 地形积雪 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 可打印的地形适配雪层、雪面上的路线及四色实体材料导出。

**Architecture:** 关闭积雪时维持原生成路径；开启时根据原地形构造连续雪厚场，再分区生成路线和统一外壳。同时保留山体、雪和路线的闭合材料体积，彩色导出使用这些体积，STL/预览使用外壳。

**Tech Stack:** TypeScript、现有多边形分区、React/Electron、标准 3MF/OBJ。

**Spec:** ../specs/2026-10-12-snow-design.md

## Global Constraints

- 在独立目录开发，不安装或修改共享依赖。验证后按用户追加要求合入 V0.4.3，仅应用积雪差异并保留其他任务改动。
- snowEnabled=false、snowCoveragePercent=30、snowMaxThicknessMm=1；允许 0–100%、0.1–10 mm。
- 白雪固定 #ffffff，maxColors 接受 2 | 3 | 4。
- 启用积雪时需要四色，旧项目缺失新字段按默认值补全。

## Review Focus

- 雪厚归零的薄边、路线与雪线相交处不得产生开边或零体积材料。
- 多段路线和触及边框的路线保持原行为；雪下山体仍有独立闭合体积。
- 0% 与关闭积雪不增加无效白色材质；100%与平坦地形不产生 NaN。
- 单一装配的多材料组件保留同一毫米坐标，不被当成分开摆放的模型。
- 项目恢复、改色、过期状态和真正导出在主进程验证，不只验证 UI。
