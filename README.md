# 徒步地形工坊 · 使用手册

适用版本：**Windows 64 位 v0.3.3 个人验证版**。更新日期：2026-10-10。

徒步地形工坊把两步路等软件导出的 **GPX 路线**，与对应区域的地形高程结合，生成山体、凸起路线、底座和可选外沿融为一体的模型，最后保存为 **一个 STL 文件**。

路线贴合山体起伏，沿模型竖直方向固定高出地表 **1 mm**，默认线宽也是 **1 mm**。不需要另外组装路线，也不需要解压三份打印文件。当前软件只导出 STL，没有 STEP／STP 或 3MF 导出入口。三维预览中的红色用于辨认路线，STL 本身不保存颜色。

## 启动软件

保留完整的 [TerrainWorkshop-win32-x64 软件文件夹](./desktop/release/v0.3.3/TerrainWorkshop-win32-x64/)，双击其中的 [TerrainWorkshop.exe](./desktop/release/v0.3.3/TerrainWorkshop-win32-x64/TerrainWorkshop.exe)。

- **不要只复制 EXE。** `resources` 文件夹、运行时文件及许可文件需要一起保留；移动软件时请移动整个文件夹。
- 使用打包好的软件不需要安装 Node.js，不需要打开终端，也不需要启动网站或开发服务。
- 自动获取新的地形区域需要联网；自带示例和合规的本地高程文件可以离线建模。
- 小窗口下，左侧设置区可以滚动。底部“生成模型／取消生成”和“保存 STL”是主要操作入口。

## 第一次使用：先试自带示例

这条流程可以在没有自己的 GPX、没有网络的情况下完成一次建模。

1. 启动软件，点击左侧 **“打开龙泉山示例”**。
2. 软件载入示例路线和自带的真实高程，切换为本地高程，并恢复默认模型参数。
3. 在右侧 **“地图取景”** 查看路线和山体范围。底图离线时，路线与取景仍可查看和调整。
4. 点击底部 **“生成模型”**。完成后，软件自动切换到 **“三维模型”**。
5. 用鼠标旋转模型，检查山体、红色路线和底座；点击 **“保存 STL”**，选择保存位置。

默认山体为 **120 × 80 mm**，外沿宽 **3 mm**，所以矩形模型的最终外尺寸在水平两个方向上为 **126 × 86 mm**；总高度由地形和参数决定，以生成后的“成品外尺寸”为准。

示例用于体验与验证功能，不代表你的实际徒步记录。

## 制作自己的路线地形

1. **准备路线。** 从两步路或其他轨迹软件导出 `.gpx` 文件并保存到电脑。当前不直接读取分享链接、截图或 KML。
2. **导入 GPX。** 点击“导入路线”，选择文件。导入后检查路线名称、距离、点数及段数，确认是你要制作的路线。
3. **选择高程来源。** 一般使用“自动获取 · Copernicus GLO-30”；已有合规的地形文件时，切换为“使用本地 GeoTIFF”，再点“选择高程”。
4. **调整山体范围。** 在地图上查看绿色取景轮廓，通过拖动十字、点选中心、修改地面取景宽度或旋转，让需要保留的路线落在范围内。
5. **设置打印尺寸。** 在“模型尺寸”选择外形、山体尺寸、路线宽度和垂直夸张；需要时展开“更多设置”。
6. **生成并检查。** 点击“生成模型”，查看三维结果和实际外尺寸。觉得范围或高度不合适时，修改参数，再点“重新生成”。
7. **保存。** 点击“保存 STL”，选文件夹和文件名。保存成功后，底部显示文件路径。打印时使用这一个 STL。

**三个容易混淆的尺寸：**

| 操作或参数 | 实际改变什么 | 示例 |
| --- | --- | --- |
| 地图放大、缩小或拖动背景 | 只改变你看的地图视野 | 放大查看某个弯道，不会改变打印区域 |
| 地面取景宽度 | 模型包含多少真实地理范围 | 3 km 宽的山地区域 |
| 山体长度／山体宽度 | 把选中的山地缩成多大的模型 | 120 × 80 mm 的山体 |

修改地面取景范围、成品尺寸比例或外形会影响地理选区。不要把“放大地图”当成“缩小山体取景”。

## 界面各部分有什么功能

界面由左侧设置区、右侧工作区和底部任务栏组成。菜单栏提供退出、文字编辑、版本信息和许可说明。

### 1. 路线与高程

| 项目 | 功能与用法 |
| --- | --- |
| 导入路线／更换路线 | 使用系统文件选择窗口导入一份 GPX。更换路线后，取景中心和地面范围重新自动计算；其他模型参数继续保留。 |
| 路线信息 | 显示路线名称、文件名、距离、点数、段数；存在无效点时显示跳过提示，并保留分段。 |
| 地形高程 | 在自动获取 Copernicus 高程与本地 GeoTIFF 之间切换。 |
| 仅使用已缓存高程 | 只在自动高程模式出现。勾选后，高程获取仅使用本机已有的合格缓存；缺少所需窗口时明确报错。此开关不限制地图底图联网。 |
| 选择高程／更换高程 | 本地模式下导入一份 `.tif` 或 `.tiff`。文件必须覆盖当前取景及所需采样邻域。 |
| 打开龙泉山示例 | 载入自带 GPX 和真实地形，用默认模型参数体验完整流程。 |
| 恢复上次项目 | 有最近项目记录时出现。重新读取上次输入文件，恢复项目参数与取景；随后仍需点击生成。 |

支持的输入：

| 类型 | 要求 |
| --- | --- |
| GPX 路线 | `.gpx`，最大 **2 MB**，源轨迹点数不超过 **5 万点**；必须含可用经纬度。 |
| 本地高程 | `.tif`／`.tiff`，最大 **256 MB**；单波段、北向、明确标注 **EPSG:4326**，高程数值已经以**米**表示。 |
| 当前不支持的本地高程 | UTM 等其他投影、旋转栅格、非米制高程、非单位 Scale／Offset；需要先用地理数据工具转换或裁剪。 |

GPX 提供路线位置，DEM 提供山体高度。软件按 DEM 生成地形，**不是用 GPX 记录的海拔直接拉出一座山**。

文件也有拖入入口：可以拖入一份 GPX、一份 GeoTIFF，或各一份；不支持一次拖入多份路线或多份高程。**v0.3.3 的资源管理器跨窗口拖入仍待人工验收，当前优先使用“导入路线／选择高程”。**

### 2. 地形取景

| 参数或操作 | 默认／范围 | 功能 |
| --- | --- | --- |
| 地面取景宽度 | 自动计算；手动可设 **0.001–100 km** | 指定真实地理范围的宽度。越大，包含区域越广；同样毫米尺寸下，细节会被缩得更小。 |
| 取景旋转 | **0°**；**−180–180°** | 转动地理选区相对于路线的朝向，便于摆放长条路线。 |
| 恢复自动取景 | 按钮 | 清除手动中心和地面宽度，重新按路线、模型外形和留白计算范围；不会把全部模型参数恢复为默认值。 |
| 输入取景中心 | 展开后输入经纬度 | 精确指定中心。纬度限 **−80–80°**，经度限 **−180–180°**。 |

地图上的绿色轮廓表示山体取景，红线表示 GPX 路线，十字表示取景中心。

固定地面宽度或移动中心后，软件不会再自动扩大范围来容纳整条路线。**取景外的路线不会出现在成品中**；如果要保留完整路线，请先在地图上检查是否全部落入轮廓。

### 3. 模型尺寸

| 参数 | 默认／可选值 | 功能与影响 |
| --- | --- | --- |
| 成品外形 | **矩形**；也可选圆形、正多边形 | 决定山体轮廓，轮廓以外的地形和路线会裁去。 |
| 多边形边数 | **6 边**；可选 **3–8 边** | 仅正多边形显示，用于选择三角形到八边形。 |
| 山体长度／山体宽度 | **120 × 80 mm**；各 **10–500 mm** | 仅矩形显示。设置山体本身的水平尺寸，不包含外扩的外沿。 |
| 外接圆直径 | **120 mm**；**10–500 mm** | 圆形和正多边形显示。多边形按外接圆直径定义，实际外尺寸见生成结果。 |
| 路线宽度 | **1 mm**；**0.4–5 mm** | 红色浮雕路线带的宽度。较宽的路线更醒目，也会覆盖更多附近地形。 |
| 垂直夸张 | **2 倍**；**0.1–20 倍** | 相对于水平缩尺放大地形高差。1 倍表示按该水平比例缩放地形高差；增大后山峰更突出。 |

**路线突出高度固定为 1 mm，没有单独高度滑块。** 改变垂直夸张会改变山体起伏，路线仍在最终地表上高出 1 mm。这里的 1 mm 按模型竖直方向计算。

### 4. 更多设置

点击“更多设置”展开。

| 参数 | 默认／范围 | 功能与影响 |
| --- | --- | --- |
| 底座厚度 | **2 mm**；**0.5–30 mm** | 设置地形最低处下方的基础厚度，使模型有平底。它不等于模型的总高度。 |
| 外沿宽度 | **3 mm**；**0–20 mm** | 在山体外围增加一体外沿；设为 0 关闭。外沿会增加最终水平外尺寸。 |
| 建模精度 | **标准 · 129 点**；快速 65 点／精细 257 点 | 指最长方向的地形采样点数，短边按比例计算。精细模式通常面数更多、耗时更长；不代表单条路线的点数。 |
| 地形平滑 | **原始高程**；轻度／中度／重度平滑 | 减弱高程噪声和局部毛刺。平滑越强，细小地形与尖峰也可能被削弱。 |
| 自动取景留白 | **10%**；**0–40%** | 自动计算范围时给路线周围留空间。已经手动指定地面宽度时，此项不可编辑。 |
| 圆角半径 | **0 mm** | 给矩形或正多边形轮廓加圆角；圆形不显示此项。上限随尺寸和外形变化。 |

先用“标准 · 129 点”查看结果，再按需要提高精度。把 30 m 高程采样得更密，**不能增加原始数据中不存在的山地细节**。复杂路线配合高精度可能触及模型面数限制，此时降低精度或缩小路线范围后重试。

### 5. 本地缓存

展开“本地缓存”，可查看高程缓存、地图底图缓存占用和数据目录位置。

- **清理缓存**同时清理高程和底图缓存。
- 清理不会删除已经保存到你指定位置的 STL，也不会删除你自行选择的原始 GPX／GeoTIFF。
- 清理后，自动高程和未缓存底图需要重新联网获取；自带示例和你提供的本地 DEM 仍可使用。
- 高程缓存保存的是取景所需的地理窗口，**不是整座山或整张大区域地图的离线包**。

缓存范围与离线使用的关系见下文。

### 6. 地图取景工作区

右侧“地图取景”页用于选定模型的地理范围。

| 操作 | 功能 |
| --- | --- |
| 拖动地图背景 | 平移你看到的地图，不改变模型取景中心。 |
| 滚轮或右下角“＋／−” | 放大、缩小地图视野，不改变实际取景范围。 |
| 拖动十字 | 移动模型取景中心。 |
| 点选中心 | 先点按钮，再点击地图上的目标位置，移动取景中心；“取消点选”或 Esc 可退出点选。 |
| 显示全貌 | 调整地图视野，让路线和取景轮廓一起显示；不重置取景参数。 |
| 底图 | 显示或隐藏 OpenStreetMap 底图；路线和轮廓继续显示。底图开关不随重启保存。 |

底部图例还显示当前地面范围的宽、高，单位为 km。顶部“自动取景／手动取景”提示当前取景方式；出现“此前结果 · 请重新生成”说明旧模型已不对应当前输入。

底图未完整加载时，仍可用路线、轮廓和左侧取景参数继续操作。地图显示异常时，界面会提示使用左侧参数，并提供“重试地图”入口。

### 7. 三维模型工作区

“生成模型”成功后自动显示实际打印网格。也可点击“三维模型”页切换查看。

| 操作或信息 | 功能 |
| --- | --- |
| 鼠标左键拖动 | 旋转观察山体与路线。 |
| 鼠标滚轮 | 放大、缩小模型显示，不改变 STL 的实际尺寸。 |
| 鼠标右键拖动 | 平移模型视野。 |
| 俯视 | 从上方检查路线走向和轮廓裁切。 |
| 恢复视角 | 回到能完整观察模型的默认视角，不改变模型参数。 |
| 成品外尺寸 | 显示生成模型真实的长、宽、总高，单位为 mm；已包含外沿。 |
| 高程来源 | 显示本地高程或自动数据来源，以及在线获取／缓存使用信息。 |
| 打印文件 | 表明导出结构为一个 STL、一个闭合实体。 |
| 三角面 | 显示网格面数，用来了解模型复杂程度。 |

## 高程数据、联网与离线使用

自动高程使用 **Copernicus GLO-30**，分辨率约 **30 m**，不需要个人 API Key。它属于 **DSM（数字表面模型）**，可能包含树木、建筑等地表信息；不是严格的裸地 DTM。若对细节或裸地地形有更高要求，可以使用符合输入条件的本地高程文件。

| 使用方式 | 是否需要联网 | 注意事项 |
| --- | --- | --- |
| 打开龙泉山示例 | 建模不需要 | 使用随软件附带的高程。地图底图可能仍尝试联网。 |
| 自动高程获取新窗口 | 需要 | 成功获取并校验后，可缓存该窗口。 |
| 自动模式＋仅使用已缓存高程 | 高程获取不联网 | 必须命中所需地理窗口的完整缓存；地图底图联网独立于此开关。 |
| 本地 GeoTIFF | 建模不需要 | 文件需满足格式要求，并覆盖取景及所需采样邻域。 |

移动中心、旋转取景、改变地面宽度，或改变外形／尺寸比例导致窗口变化后，可能需要新缓存。即使新区域看起来离上次很近，也不能假定已有缓存完整覆盖。

自动获取限于局部取景：纬度 **±80°** 内，暂不支持跨日期变更线；还受最多 **9 个高程瓦片、400 万选区像元、每个方向最多 2°** 的限制。遇到范围过大提示时，缩小选区或使用裁剪后的本地高程。

## 关闭软件后如何继续

软件会保存有效的模型参数、高程来源和“仅使用已缓存高程”设置，以及最近一个项目的输入文件位置与取景。

1. 再次启动时，先恢复参数偏好；不会自动导入旧 GPX／DEM，也不会自动开始计算。
2. 点击 **“恢复上次项目”**，软件重新读取上次文件，恢复取景中心、地面范围和项目参数。
3. 检查地图与参数，然后点击 **“生成模型”**。
4. 成功后重新保存 STL，或继续使用你此前已保存的 STL 文件。

恢复记录**不是一个打包的项目文件**：原始 GPX／GeoTIFF 没有被完整复制进去。文件被移动、删除、修改或变得无法读取时，会提示重新导入；尽量保留原始输入文件的位置和内容。

旧三维预览、运行中的任务和旧 STL 不会随项目恢复。界面也没有“另存项目”或多项目列表入口；当前保留的是最近一个项目。

软件只保存有效参数。参数不合法或出现“设置未能保存”提示时，请先修正或处理提示，再关闭。**快速改参后立即退出并重启的原生验收仍未完成**，目前不把这一边界场景视为已验收通过。

## 保存文件与打印前检查

点击“保存 STL”会打开 Windows 系统保存窗口：

- 可以选择文件夹、修改文件名，支持中文和空格。
- 文件名没有后缀时，软件自动补上 `.stl`。
- 如果目标文件已经存在，需要确认是否覆盖。
- 取消保存窗口会返回软件，当前模型仍可继续查看和保存。
- 成功后只写出 **一个 STL**；不需要额外的路线文件或底座文件。

STL 顶点坐标按 **毫米（mm）**输出。STL 格式本身不记录单位，导入切片软件时请按毫米解释，并与界面“成品外尺寸”对照。直接在切片软件里缩放整个 STL，也会同时缩放路线的 1 mm 突出高度；需要改变成品尺寸时，优先在本软件里改尺寸并重新生成。

打印前至少检查：

1. 实际外尺寸是否适合你的打印平台，路线是否全部保留。
2. 山体高度、路线可辨认程度和底座厚度是否合适。
3. 切片软件是否报告模型问题，以及分层预览中路线、陡坡、底座是否正常。
4. 完成小样验证后，再打印正式模型。

当前版本已完成网格与单 STL 保存检查，**目标切片软件和实物打印验收仍属于阶段 4**。独立审查记录了样品少量极小面的存储法线与顶点方向不一致，阶段 4 需结合切片结果复核，详情见 [阶段3.3-实现与验收.md](./阶段3.3-实现与验收.md)。

## 常见问题

| 遇到的情况 | 原因与处理 |
| --- | --- |
| “生成模型”是灰色的 | 检查是否已导入 GPX；本地模式是否已选 DEM；数值是否为空或越界；取景是否正在更新。具体原因通常显示在底部。 |
| “保存 STL”是灰色的 | 尚未成功生成、预览仍在加载，或输入／参数已改变。按当前设置重新生成。 |
| 地图放大了，成品范围没变 | 地图缩放只改变视野。修改“地面取景宽度”，或移动十字调整中心。 |
| 部分路线没有出现在模型上 | 可能超出取景轮廓。扩大地面范围、移动中心、旋转选区，或恢复自动取景后重新生成。 |
| 底图空白或不完整 | 查看网络情况，或关闭“底图”继续操作。地图底图与建模高程是两套数据；底图空白不一定表示高程不可用。 |
| 提示没有可用高程缓存 | 取消“仅使用已缓存高程”，联网获取当前窗口；或改用覆盖该区域的本地 GeoTIFF。 |
| 本地 DEM 无法使用 | 检查格式、坐标系、单位、文件大小和覆盖范围；不能把普通图片当成高程 GeoTIFF。 |
| GPX 无效、太大或点数过多 | 重新导出有效 GPX，或先裁剪／简化路线，满足 2 MB 和 5 万点限制。 |
| 生成很慢，或提示面数／高度超限 | 降低建模精度、减少复杂路线范围，或按提示调整垂直夸张。软件不会静默生成平地来代替失败的地形。 |
| 取消后还看到旧模型 | 那是此前预览，不表示刚才任务已完成。等待取消结束，再按当前参数重新生成。 |
| 重启后没有上次三维模型 | 这是当前恢复方式：恢复输入和参数，再重新生成；已保存的 STL 可以直接在切片软件中打开。 |
| 预览是红线，打印文件却没有红色 | STL 不保存颜色。文件保留的是凸起路线几何；颜色需要后续打印或涂装处理。 |
| 三维显示中断或电脑无法显示三维 | 按界面提示，切换到地图页再返回模型页尝试重载；若生成已成功且保存按钮可用，可保存 STL，在切片软件查看。 |
| 只拷贝 EXE 后无法启动 | 重新保留完整软件文件夹，再打开其中的 EXE。 |
