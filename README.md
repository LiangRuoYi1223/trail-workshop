# 徒步地形工坊 · 使用手册

适用版本：**Windows 64 位 v0.4.10**。更新日期：2026-10-14。

徒步地形工坊将两步路等软件导出的 **GPX／KML 徒步路线**，与对应区域的地形高程结合，生成山体、凸起路线、底座和可选外沿组成的三维打印模型。支持 **彩色 3MF、OBJ 材质包和 STL**，也可以添加实际有厚度的积雪层。

路线贴合地形起伏，默认宽度和凸起厚度均为 **1 mm**。草地、山石、路线颜色可调整；使用地表影像时，可以分别调整草地识别强度和连片程度。

## 启动软件

使用 Windows 发行包时，解压完整文件夹，双击其中的 `TerrainWorkshop.exe`。

软件右上角“支持作者”左侧的 **“使用说明”** 可查看六步入门流程和每个板块的用途、操作方法。说明自带目录，断网可阅读；点击“关闭说明”、按 Esc 或点击窗口外侧可返回软件。

- 保留 EXE、`resources`、运行时和许可文件；移动软件时移动整个文件夹。
- 使用发行包无需安装 Node.js 或启动开发服务。
- 左侧设置区可以滚动，底部提供生成、取消、输出格式和保存操作。
- v0.3.6 起，桌面版从导入用户自己的路线开始；旧版“打开龙泉山示例”入口已移除。

本仓库的发行目录与 ZIP 包由打包流程生成，不纳入 Git。源码运行与打包方法见[开发与验证](#开发与验证)。

## 第一次使用

1. **准备路线。** 从轨迹软件导出一份 `.gpx` 或 `.kml` 文件并保存到电脑。
2. **导入路线。** 点击“导入路线”，或将路线文件拖入软件。检查名称、距离、点数和段数。
3. **选择高程。** 通常使用“自动获取 · Copernicus GLO-30”；已有地形文件时选择“使用本地 GeoTIFF”。
4. **选择地表影像。** 想区分草地与山石时选择“12个月”“24个月”或本地影像；选择“不使用”可生成统一山体配色。
5. **调整取景和尺寸。** 确认要保留的路线都在取景轮廓内，再设置成品外形、尺寸和路线宽厚。
6. **生成并检查。** 点击“生成模型”，完成后在“三维模型”查看路线、山体和实际外尺寸。需要调整时修改参数并重新生成。
7. **保存。** 在底部选择彩色 3MF、OBJ 材质包或 STL，再点击对应保存按钮。

默认矩形山体为 **120 × 80 mm**，外沿宽 **3 mm**，所以水平外尺寸为 **126 × 86 mm**。总高度以生成后的“成品外尺寸”为准。

## 路线与高程

| 输入或操作 | 要求与说明 |
| --- | --- |
| GPX／KML 路线 | 每份最大 **32 MB**，最多 **5 万个源坐标点**，必须含可用经纬度。 |
| 大文件提醒 | 路线超过 **2 MB** 会提示计算可能较慢；超过 32 MB 则拒绝导入。 |
| 导入／更换路线 | 每次接受一份路线。更换后重新计算自动取景，保留其他模型参数。 |
| 本地高程 | `.tif`／`.tiff`，最大 **256 MB**；单波段、北向、明确声明 **EPSG:4326**，高程数值以**米**表示。 |
| 本地高程覆盖 | 必须覆盖取景及所需采样邻域。其他投影、旋转栅格或非米制高程需先转换。 |
| 恢复上次项目 | 重新读取最近项目的输入文件，恢复参数与取景；恢复后需要重新生成。 |

KML 支持折线及多段轨迹；只有地点、面或网络链接的文件不能作为路线导入。软件保留独立分段，遇到无效点时会断开路线并提示。

可以拖入一份路线、一份高程，或各一份。地表影像应拖到“地表与打印颜色”区域，并先选择“本地导入”。

**路线提供地理位置，DEM 提供地形高度。** 山体依据 DEM 生成，GPX 中记录的海拔不直接作为山体表面。

## 地图取景

地图上的绿色轮廓表示山体范围，红线表示路线，十字表示取景中心。

| 操作 | 实际改变什么 |
| --- | --- |
| 拖动背景、滚轮或“＋／−” | 改变地图视野。 |
| 拖动取景顶点 | 等比例调整地理取景范围。 |
| 拖动十字、点选中心 | 移动取景中心。 |
| 右键中心选择“旋转取景” | 调整选区朝向。 |
| 输入取景中心 | 精确指定经纬度；纬度 −80–80°，经度 −180–180°。 |
| 恢复自动取景 | 清除手动中心与地面范围，按路线、外形和留白重新计算。 |
| 显示全貌 | 让路线与取景轮廓一起出现在视野内。 |
| 底图开关 | 显示或隐藏地图底图；此开关不随重启保存。 |

三个尺度需要分清：

| 尺度 | 用途 | 示例 |
| --- | --- | --- |
| 地图缩放 | 看清某一段路线 | 放大一个弯道 |
| 地面取景宽度 | 决定包含多少真实地理范围 | 3 km 的山地区域 |
| 山体长度／宽度 | 决定选区缩成多大的打印模型 | 120 × 80 mm |

手动移动中心或固定地面范围后，取景不会自动扩大来容纳全部路线。取景外的路线会被裁去，生成前请检查轮廓。

## 模型尺寸与路线样式

| 参数 | 默认／范围 | 用途 |
| --- | --- | --- |
| 成品外形 | 矩形、圆形、正多边形 | 选择山体轮廓。 |
| 矩形山体尺寸 | **120 × 80 mm**；各 10–500 mm | 设置山体水平尺寸，不包含外沿。 |
| 圆形／多边形直径 | **120 mm**；10–500 mm | 按外接圆直径定义。 |
| 多边形边数 | **6**；3–8 边 | 仅正多边形显示。 |
| 路线宽度 | **1 mm**；0.4–5 mm | 设置凸起路线带的宽度。 |
| 路线凸起厚度 | **1 mm**；0.1–10 mm | 沿模型竖直方向高出最终地表。 |
| 垂直夸张 | **2 倍**；0.1–20 倍 | 放大地形高差。 |
| 底座厚度 | **2 mm**；0.5–30 mm | 设置地形最低处下方的平底厚度。 |
| 外沿宽度 | **3 mm**；0–20 mm | 设为 0 可关闭外沿。 |
| 建模精度 | 快速 65／**标准 129**／精细 257 点 | 增加地形采样密度，也会增加面数与计算量。 |
| 地形平滑 | 原始、轻度、中度、重度 | 减弱噪声；强平滑也会削弱地形细节。 |
| 自动取景留白 | **10%**；0–40% | 自动范围周围的留白比例。 |
| 圆角半径 | **0 mm**；上限随外形变化 | 为矩形或多边形增加圆角。 |

路线厚度独立于垂直夸张。先用标准精度查看，再按需要提高精度；增加采样点不能补出原始高程中没有的细节。

## 地表影像与打印颜色

| 影像来源 | 行为 |
| --- | --- |
| 不使用 | 山体表面统一配色，高程与路线照常生成。 |
| 最近一个夏季 | 按选区获取最近一个夏季（6–8月）的 Sentinel-2 真彩色影像。 |
| 最近两个夏季 | 获取最近两个夏季（6–8月）的影像，也是默认来源设置。 |
| 本地导入 | 使用覆盖选区的 RGB／RGBA GeoTIFF。 |

本地地表影像最大 **64 MB**、最多 **16,777,216 像素**，须为北向、8 位 RGB／RGBA，明确声明 **EPSG:4326 或 EPSG:3857**。普通照片或地图截图不能直接替代有地理坐标的 GeoTIFF。

自动影像不是实时画面，会筛除云、云影和无效像元。完成后可查看实际拍摄日期与缓存状态；所选月份内无可用影像或覆盖不足时，按提示重试或切换本地导入。

草地、山石、白雪、路线、底座、文字共用一个颜色盘，点击角色色块后调整色盘、明度和 RGB。底座始终打印；草地与山石至少保留一项。相同 RGB 合并计数，界面显示实际颜色数，无需手动选择两色、三色或四色预算。雪色固定白色。

勾选“文字”后，在“底座与文字”输入一行底座凸字（最多 32 个 Unicode 字符），设置 **1.5–10 mm** 的字号，默认 **3 mm**、固定凸起 **0.6 mm**。文字沿正面外沿居中，必要时自动增加外沿。改文字或字号需要重新生成，改底座或文字颜色即时用于预览与彩色导出。关闭文字会保留原输入，但不生成凸字。

圆形可在地图上拖拽“文字位置”手柄旋转，也可输入 **0–360°** 的绝对角度或使用滑块。0° 在模型上方、90° 右方、180° 下方、270° 左方；360° 与 0° 同位。文字整行沿圆周切线摆放，随取景朝向旋转。

多边形可点击地图上的边编号，或输入 **第 1–N 边** 序号，文字会在所选边居中。第 1 边为模型正前方下边，其后向右沿周边编号；减少边数时保留有效选择。地图显示本机字体的真实字形、孔洞和最终外沿，生成前即可查看位置与字号；改变位置后需重新生成。

## 草地识别与连片修正

两个滑块均为 **0–100，默认 50**，随项目保存和恢复。

| 滑块 | 向左调整 | 向右调整 |
| --- | --- | --- |
| 草地识别强度 | 收紧绿色判断，保留更多山石。 | 放宽绿色判断，增加草地。 |
| 草地连片程度 | 保留更多碎石细节；**0 关闭连片**。 | 填补被草地包围的小块山石和短缝，让草地覆盖连续。 |

草地偏少先调整识别强度；绿色识别已经合适但草地内部过碎时，再调整连片程度。大片山石、长岩石带及连接大岩体的分支会保留。每个滑块都有独立“恢复默认”按钮。

识别依据影像颜色与空间关系，树林等绿色植被也可能归入草地代表色。滑块数值表示调整强度，**不代表实际草地覆盖百分比**。修改后旧模型会标记为过期，需要重新生成。

不使用影像、本地影像尚未导入、草地与山石未同时选中或正在生成时，识别控件不可用。

## 积雪设置

在共用颜色盘中勾选白雪可开启积雪。雪层从较高区域向较低区域覆盖，雪线渐薄，陡坡积雪更薄；路线在当地最终雪面上凸起。

| 参数 | 默认／范围 |
| --- | --- |
| 积雪开关 | 默认关闭。 |
| 积雪覆盖率 | **30%**；0–100%，按模型俯视面积计。 |
| 最大厚度 | **1 mm**；0.1–10 mm，沿模型竖直方向计。 |
| 雪色 | 固定白色。 |

界面会显示生成后的实际覆盖率。修改开关、覆盖率或厚度需要重新生成；积雪设置随项目保存和恢复。

## 生成与三维预览

底部“生成模型／重新生成”开始建模；生成中可点击“取消生成”，等待任务停止后再操作。界面显示高程、影像与模型阶段，以及下载、缓存和覆盖信息。

生成成功后自动切到“三维模型”，显示对应最终打印结果的网格。

| 操作或信息 | 用法 |
| --- | --- |
| 左键拖动 | 旋转观察。 |
| 右键拖动 | 平移视野。 |
| 滚轮 | 放大、缩小显示。 |
| 俯视／恢复视角 | 检查路线与轮廓，或回到完整视角。 |
| 成品外尺寸 | 查看含外沿的长、宽、总高，单位为 mm。 |
| 高程／影像来源 | 查看数据来源、拍摄日期及缓存情况。 |
| 三角面数 | 了解模型复杂程度。 |

改变路线、取景、几何、影像或识别设置后，旧结果需要重新生成才能保存。关闭软件会结束正在进行的计算，未保存的模型不会在下次启动时恢复。

## 保存文件与打印

在底部“输出格式”选择格式，再点击对应保存按钮。系统保存窗口可修改目录与文件名，支持中文和空格；已有同名文件时需确认覆盖。

| 格式 | 保存内容与用途 |
| --- | --- |
| 彩色 3MF | 毫米单位的模型与有限颜色材料。积雪启用时保留山体、雪层、路线的闭合材料实体。 |
| OBJ 材质包 | ZIP 内包含 OBJ、MTL、调色板和记录。解压后将 OBJ 与 MTL 保持同目录。 |
| STL | 保存统一外形，不保存颜色；坐标按毫米输出。 |

彩色文件需要在目标切片软件中核对颜色与耗材映射；积雪材料应映射为白色。STL 导入时按毫米解释，并与软件“成品外尺寸”对照。

打印前检查：

1. 实际外尺寸是否适合打印平台，要保留的路线是否都在模型中。
2. 路线宽厚、山体高度、底座和外沿是否合适。
3. 切片软件的材料映射、模型检查与分层预览是否正常。
4. 先做小样，再决定正式打印。

## 关闭软件后如何继续

软件保存有效参数、高程与影像来源、缓存设置，以及最近项目的输入文件位置和取景。

1. 再次启动时恢复参数偏好。
2. 点击“恢复上次项目”，重新读取最近的 GPX／KML、本地高程和地表影像。
3. 检查取景与参数，重新生成，再保存当前模型。

恢复记录保存的是文件路径与校验信息。移动、删除或改动输入文件后，可能需要重新选择。最近项目不包含旧三维预览、旧任务或已导出的模型；请自行保留保存的打印文件。

## 联网、离线与缓存

自动高程使用约 **30 m** 分辨率的 Copernicus GLO-30，无需个人 API Key。它是可能包含植被与建筑物的数字表面模型（DSM）。

| 使用方式 | 联网需求 |
| --- | --- |
| 自动高程获取新选区 | 需要联网，成功后缓存所需窗口。 |
| 仅使用已缓存高程 | 高程只读已有合格缓存；缺失时提示。 |
| 自动地表影像 | 首次获取需要联网，可复用符合月份限制的已验证缓存。 |
| 本地高程／本地地表影像 | 输入文件覆盖选区时，可在本地建模。 |
| 地图底图 | 与建模数据独立；可关闭底图继续取景。 |
| 支持作者收款码 | 本地图片，断网可显示。 |

“本地缓存”可查看数据目录与占用，并清理高程、影像和底图缓存。已保存的打印文件及自行导入的源文件不会因清理缓存而被删除。

缓存按地理选区保存。移动中心、旋转或改变范围后，可能需要重新获取对应数据。遇到选区过大、缺值或覆盖不足提示时，缩小范围或使用裁剪后的本地数据。

## 支持作者

点击软件右上角 **“支持作者”**，弹窗显示作者提供的微信收款码。图片保持原图内容与比例，随软件本地保存。

可点击“关闭收款码”、按 Esc 或点击弹窗外侧返回；关闭后焦点回到顶部按钮。

## 常见问题

| 情况 | 检查与处理 |
| --- | --- |
| 生成按钮是灰色的 | 检查路线、本地高程、参数是否合法，以及取景是否仍在更新。 |
| 保存按钮是灰色的 | 等待生成与预览完成；输入或识别设置改变后重新生成。 |
| 路线文件太大 | 超过 32 MB 或 5 万点时，先裁剪／简化；超过 2 MB 的提醒可确认后继续。 |
| 部分路线缺失 | 检查是否超出取景范围；扩大范围、移动中心或旋转后重新生成。 |
| 草地偏少／偏多 | 调整“草地识别强度”，重新生成对比。 |
| 草地内部碎石太多 | 适当增加“草地连片程度”；设为 0 可对比原始颜色分类。 |
| 草地滑块不可用 | 同时选中草地与山石，并使用可用地表影像。 |
| 自动影像失败 | 检查网络或更换月份范围；按提示重试，也可使用本地 RGB GeoTIFF。 |
| 本地文件无法使用 | 分清高程与地表影像的格式要求，检查坐标系、覆盖范围与大小。 |
| 地图空白 | 底图与高程独立，可关闭底图继续；按地图提示重试加载。 |
| 缺少高程缓存 | 联网获取对应选区，或导入覆盖该区域的本地高程。 |
| 生成慢或面数超限 | 降低精度、简化路线或缩小选区，再按提示重试。 |
| STL 没有颜色 | 使用彩色 3MF 或 OBJ 材质包保存颜色。 |
| 重启没有旧模型 | 恢复输入与参数后重新生成；已保存模型可在切片软件中打开。 |
| 只复制 EXE 后无法启动 | 重新保留完整软件文件夹。 |

## 开发与验证

开发环境需要 **Node.js 24 或更高版本**。在仓库根目录运行：

```powershell
npm ci
npm run desktop:dev
```

常用命令：

```powershell
# 核心测试
npm test

# 桌面逻辑与真实计算进程测试
npm run desktop:test

# TypeScript 检查与桌面界面构建
npm run desktop:build

# Windows 发行包
```
